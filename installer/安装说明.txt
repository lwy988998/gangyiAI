钢一定制AI v5.7.2

系统要求
- Windows 10 或 Windows 11，64 位系统。
- 安装包已内置 Microsoft Edge WebView2 Runtime，安装过程不需要联网。

安装
1. 将安装包复制到任意 Windows 电脑。
2. 双击安装程序并按提示完成安装。
3. 安装完成后，可从桌面或开始菜单启动“钢一定制AI”。

数据位置
- 程序配置、AI 服务设置、课程与聊天数据库保存在当前用户的
  %LOCALAPPDATA%\GangyiAI 目录。
- 卸载程序不会自动删除该目录中的学习档案。

说明
- 当前安装包尚未使用商业代码签名证书，Windows SmartScreen 可能提示“未知发布者”。
- AI 问答需要用户自行配置可用的 AI 服务地址、模型和 API Key。
- 联网搜索需要用户自行配置可用的搜索服务。
