# 钢一定制AI

钢一定制AI 是面向柳州市钢一中学的 Windows 本机 AI 学习平台，当前版本为 **v5.7.0**。本版采用 A「澄明」蓝白界面，统一顶部导航、留白与字体层级，并新增以讲义、翻页课件和辅助答疑为主的深度课程。使用 C++17、Crow、SQLite、WebView2 和原生 HTML/CSS/JavaScript，课程与学习记录保存在本机，无需在线账号。

快速规划承接现有教学逻辑；新深度课程支持任意领域的学习目标，先生成大纲，再逐课生成与保存内容。已有课程、作答、草稿、进度、资料库、画像、模型设置和密钥继续保留。需要联网时沿用两家同时搜索、合并去重和来源记录，分别显示请求、缓存和失败状态。本版暂不实现 PPT、PDF 或图片导出，也不新增付费图像生成服务。正式发布状态与验收边界见 [v5.7.0 版本说明](docs/releases/v5.7.0.md)。

## 学习与 AI

- 首页输入学习目标或上传参考图，选择快速规划或深度课程；我的课程管理课程，“我的AI”管理统一学习安排、画像、教学偏好和学习时间。
- 当前课程恢复最近访问的有效课程；没有课程时显示“当前没有课程”，提供创建入口。
- 快速规划保留讲解、练习、小结三个独立聊天页面和固定底部输入框，各页恢复自己的交流、草稿和滚动位置。常态突出继续学习和提交答案，提示、示范、重讲等工具收进“更多”。
- 深度课程在主区域切换图文讲义与翻页课件，长课件的翻页栏保持可见；左侧提供课程目录，右侧 AI 答疑可收起，窄屏通过独立入口打开。AI 结合真实作答调整讲解、练习与后续建议，保留课程主线。
- 联网图片、时间轴、流程图、二次函数参数图和简化受力演示按教学需要选用。学生可要求补充或调整，不强制每课配齐；图片或图示失败时可继续阅读可用内容，并就地重试失败项。
- 真实 AI 主控决定教学内容、题量、难度、评价和下一课。实际作答先评价再讲解，纯追问与示范不新增评分；切换、刷新和读取已有内容不重新备课。
- 学科画像与学习能力六维图依据真实作答评估。充分性由 AI 判断，无固定三题门槛；证据不足显示待评估，六维都有有效评分后显示完整区域。
- 顶部折叠的 AI 状态详情显示任务、来源、用途、具体操作和请求次数，支持暂停全部请求、恢复未完成任务及失败重试。

详细行为见 [AI 教学主控](docs/ai-controller.md)、[深度课程协议](docs/deep-course-protocol.md)、[原课堂与页面协议](docs/v5.6.0-ai-classroom.md) 和 [AI 调用监控](docs/AI调用监控.md)。视觉规范见 [DESIGN.md](DESIGN.md)。

## 两种课堂怎么用

1. 在首页填写目标或上传参考图，选择“快速规划”或“深度课程”，提交后等待 AI 保存课程大纲。
2. 快速规划进入原有聊天课堂；通过底部输入作答或提问，需要提示、示范或换种讲法时打开“更多”。停止和失败重试在相应状态出现。
3. 深度课程从目录选课；尚未备课时点击准备入口。内容生成后可在讲义和课件间切换，打开右侧答疑提问；AI 会收到当前内容和互动参数的上下文。题卡的“提交答案”进入原真实评价流程，单纯翻页、阅读、拖动参数或答疑不增加评分。
4. 已保存课时再次进入时直接复用。素材失败只重试对应项目，保留成功讲义与素材；如果图片缓存无法显示，可用该项的修复入口重新获取。

旧课程继续使用快速规划课堂，包括原始参数为 `mode=deep` 的课程；只有新建时明确选择深度课程并保存 `pedagogy=deep-v1` 标记，才使用新课堂。升级不会批量迁移或重写旧课。

## Windows 使用

安装包从 [v5.7.0 发布页](https://github.com/lwy988998/gangyiAI/releases/tag/v5.7.0) 获取。学习增强试用版的 Windows 安装包 `gangyiAI-learning-preview1-v5.7.0-x64.exe` 与同名 ZIP 已在本机生成；免安装包完整解压后运行 `gangyiAI-launcher.exe`。版本标签的 Windows/Linux、Sanitizer 和安装检查全部成功，且同渠道升级核对原档案与凭据后才公开；版本源码见 [v5.7.0 源码树](https://github.com/lwy988998/gangyiAI/tree/v5.7.0)，运行结果见 [发布流水线](https://github.com/lwy988998/gangyiAI/actions/workflows/ci.yml)。

已安装“学习增强试用版”时，使用同渠道的新版本安装包原位升级，继续使用原试用档案；本次沿用既有安装和档案标识。升级前备份程序、学习档案和设置，并保留回退副本。正式版与试用版使用独立档案，安装其中一种不会自动合并另一种的数据。

独立窗口恢复上次大小与位置，每次冷启动显示一次蓝白启动页与加载进度。首次启动可暂不配置 AI，后续在设置中填写服务商、接口地址、模型和 API Key。密钥保存在 Windows 凭据管理器，配置与课程数据位于 `%LOCALAPPDATA%/GangyiAI`；卸载默认保留课程数据。AI 不可用时保留有效内容并提供重试。

托盘提供日志、数据目录、诊断报告、数据库备份恢复及服务重启。服务异常后按限次退避策略恢复。免安装包不携带本机档案；程序需要 WebView2 Runtime，目前未进行代码签名。

附件摘要以发布页的 [SHA256SUMS.txt](https://github.com/lwy988998/gangyiAI/releases/download/v5.7.0/SHA256SUMS.txt) 为准，校验命令：

```powershell
Get-FileHash ./gangyiAI-learning-preview1-v5.7.0-x64.exe -Algorithm SHA256
```

## 构建与验收

Windows 发布环境需要 CMake、MinGW-w64、PowerShell 和 Inno Setup 6：

```powershell
powershell -ExecutionPolicy Bypass -File ./scripts/build_windows.ps1
```

脚本下载固定版本依赖，编译、运行核心测试、自检并生成 `dist/installer` 中的安装包、免安装包及 SHA256 文件。仅编译和生成免安装包可加 `-SkipInstaller`。

本机冻结包的完整 38 项 CTest 全部通过（168.97 秒），安装包与免安装包已生成。浏览器记录覆盖全局 20 页 × 3 视口、深度课堂布局与交互、真实 C++ 服务配模拟模型的端到端流程，以及快速课堂教学请求与草稿恢复。“继续学习”已验证能定位未作答题，已评价后请求主控决定下一步，不再反复停留在首题；对应两套模拟回归通过。长课件的三视口翻页栏回归通过。这些隔离夹具验证接口、存储与交互，不证明真实模型的教学质量。

## 服务端运行

Linux 或直接运行服务时设置以下环境变量，默认只监听本机：

```text
HOST=127.0.0.1
PORT=39002
DATABASE_PATH=gangyiAI.db
AI_BASE_URL=https://api.deepseek.com/v1
AI_API_KEY=你的密钥
AI_MODEL=deepseek-chat
```

运行服务程序 `gangyiAI`。课程、画像及记录保存在指定数据库；模型请求发送至你配置的服务，页面只读查询与显示操作不属于模型推理请求。
