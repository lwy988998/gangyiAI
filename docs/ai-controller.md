# 真实 AI 教学主控

规划、课堂互动、评价、画像、目标与课表调整、未来大纲、复习、推荐和备课共用一个持久化主控。模型读取实际工具结果后决定继续、等待学生或完成；没有固定课堂板块、题量、三题画像门槛、通过率、复习间隔或每日调用额度。

## 行为与兼容

- 所有题型保存原题与真实输入，先判断实际回答、暂存评价，再请求流式讲解。完整且成功的教学步骤才发布正式评价；失败、截断、漏答、跳过与纯追问不伪造评价。
- 提示依据实际展示的事件序号记录；刷新恢复已看过的内容，中断讲解标明来源。同题多轮画像引用去重，评分充分性与不确定性由 AI 提供。
- 原有课堂链接映射到稳定课时及题目标识；课程重排保留原索引，已进入或已作答知识点受到保护。课程、课件、历史对话、进度、六维图和配置继续读取原数据。
- 下一课可推进、补弱、复习或切换课程。备课完整保存后进入同一份内容；主动请求自动进入，自主备好的课只显示通知。需要补充信息时提供输入入口。
- 调整保存前后版本及理由，可暂停、恢复或撤回。新输入、其他窗口修改和撤回阻止旧结果覆盖；未保存课表编辑转为候选，撤回后没有新反馈时不能立即重做。
- 关闭时暂停在途任务，重启恢复有效步骤。连续三次同类失败后停止，保留输入与有效结果，允许手动重试；没有本地教学模板回退。
- 状态、课程、画像与普通页面刷新只读取缓存；AI 自身保存不会重新触发学习循环。双模式六维图显示统一主控状态，不等待旧独立评分线程。

## 接口与保存

统一入口为 `/api/learning-agent/events`、`/api/learning-agent`、`/api/learning-agent/control`、`/api/learning-agent/lesson` 与 `/ws/learning-agent`。旧课堂、作答、对话和下一课接口适配到同一主控。v5.7.0 新增的 `/api/deep-course` 读取讲义／课件，`start` 与 `retry-media` 入口仍提交该主控；没有另建评分或调度系统。模型调用在事务外完成，提交时检查任务、学习版本和对象版本，在短事务内保存。

任务、事件序号、课件、暂存及正式评价、撤回记录使用现有表。公开接口与备课流仅输出学生所需内容，过滤标准答案、解析、评分材料及内部工具参数。数据库结构不新增表。

建课状态读取使用同一数据库快照。教学主控要求完整 JSON 对象，兼容只包住整份回复的单层 JSON 围栏。程序在保存前检查回复协议、整批动作的身份、工具权限及已执行动作的一致性。截断、附加对象、非法动作和工具标记须通过恢复重新生成，程序不会猜测缺失字段或语法。错误正文不进入后续恢复上下文，按原任务和已保存结果继续。

课件、备课选择、作答评价、画像、图片识别与首页推荐也使用同一个结构化回复解析入口。它拒绝重复字段、空字节、回复外的文字和截断对象。各任务继续负责校验自己的字段、上下文和权限。已有有限重试的生成任务按原次数恢复。发布构建保留测试断言，C++ 回归也检查备课截断后的错误分类。

课程规划从首轮开始使用专用的大纲协议。模型收到原学习目标、课程模式和有大小上限的画像与资料摘要，返回标题、简介及由阶段和知识点构成的大纲。原文查阅、备课及生成讲义、题目分别由后续任务处理。程序完整校验大纲后，用原学习目标和课程模式创建课程，并在同一事务中保存大纲和任务回执。恢复轮沿用同一协议，要求省去可选说明并保留目标范围。自动恢复次数有限。仍失败时，规划页显示具体原因，并允许继续同一个任务。已有在途恢复时，重复点击复用该请求。

一般教学请求出现结构错误后，恢复轮把状态放在前面，用根字段描述一个动作。没有动作时显式返回空工具。程序在解析完整回复后将该动作交给原有权限、幂等与事务检查。兼容原动作数组，混合两种格式的回复会在保存前被拒。恢复轮的学生可见文字在通过校验后展示。`teaching-reply-recovery` 纳入构建验收，运行真实故障形态的括号错误、无效混合格式、原动作不重复及继续同一任务的回归。

逐题练习的暂存评价使用专用反馈请求。模型读取本次实际作答、暂存评价、当前轮次和必要的来源上下文，返回公开反馈、帮助分类及需要的引用。反馈请求不提供工具目录。夹带教学动作的回复在发布前整体拒绝。原事务保存反馈和评价后，程序按评价决定下一题或留在当前题等待澄清。原有仅含反馈的回复格式仍可读取。

Windows 发布检查运行 `tests/plan_response_recovery_smoke.py`，覆盖首轮大纲协议、非法课程模式、正常结束但内容无效、长度截断、完整围栏、错误字段类型、额外动作、重复重试和课程去重。测试使用隔离模型与档案。

试卷识别与讲解使用同一份完整 JSON 解析规则。收到正文时先展示接收状态，完整内容校验并保存后才展示。格式或长度异常时只自动重试一次当前批次或当前问题，先前已保存的识别结果不重做。试卷原题、选中题和评分依据发生变化时，旧讲解仍由事务拒绝。Windows 发布检查覆盖第二批异常后的页码恢复与讲解重试。

## 当前课堂与验证

快速规划及旧课程的讲解、练习、小结采用三个独立聊天页面；各页独立恢复消息、草稿和滚动位置，主控仍读取同一知识点的完整学习记录。课堂交流中的追加板块与教学焦点绑定本次课时，防止内容误写到另一节课；跨页下一步提供入口，由学生点击进入。

新深度课程以最新快照中的 `pedagogy=deep-v1` 识别，原 `mode=deep` 旧课不会自动迁移。先保存大纲，进入具体课时再生成并缓存讲义、课件和按需媒体；主区阅读、右侧辅助答疑共用同一真实教学主控。讲义／课件绑定本课公开教学板块，作答仍先评价后讲解，翻页、拖动图示和纯答疑不评分；媒体失败保留有效内容并单项重试。完整结构和接口见 [深度课程协议](deep-course-protocol.md)。

统一课表只在学生手动请求后生成候选，确认后应用同一份结果；普通后台学习更新不能自动重新排课。

协议验收覆盖自主课程结构、六类题型、先评价后讲解、提示曝光、追问不评分、失败与重试、同题去重、一题画像、课程重排与撤回、复习日期、缓存和重启恢复。浏览器验收覆盖各页记录隔离、题目与输入布局、答案隐藏、流式反馈、草稿、停止、重试和窄屏。六维图覆盖空值、零分、学科选择、键盘、触屏及文本安全显示。

测试模型夹具用于验证接口与保存行为，不作为真实 AI 的教学能力证明。新增深度课程专项和浏览器夹具延续这一边界；任意领域目标不等于全领域已完成真实验收。真实模型验收使用隔离档案；Linux、Sanitizer、安装包和免安装包由 GitHub CI 完成对应提交的验证，v5.7.0 最终记录见 [版本说明](releases/v5.7.0.md)。

私人数据库、缓存、截图、真实 AI 凭据和本机升级备份不进入源码与发布包。
