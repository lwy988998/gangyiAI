# 真实 AI 教学主控

规划、课堂互动、评价、画像、目标与课表调整、未来大纲、复习、推荐和备课共用一个持久化主控。模型读取实际工具结果后决定继续、等待学生或完成；没有固定课堂板块、题量、三题画像门槛、通过率、复习间隔或每日调用额度。

## 行为与兼容

- 所有题型保存原题与真实输入，先判断实际回答、暂存评价，再请求流式讲解。完整且成功的教学步骤才发布正式评价；失败、截断、漏答、跳过与纯追问不伪造评价。
- 提示依据实际展示的事件序号记录；刷新恢复已看过的内容，中断讲解标明来源。同题多轮画像引用去重，评分充分性与不确定性由 AI 提供。
- 原有课堂链接映射到稳定课时及题目标识；课程重排保留原索引，已进入或已作答知识点受到保护。课程、课件、历史对话、进度、六维图和配置继续读取原数据。
- 下一课可推进、补弱、复习或切换课程。备课完整保存后进入同一份内容；主动请求自动进入，自主备好的课只显示通知。需要补充信息时提供输入入口。
- 调整保存前后版本及理由，可暂停、恢复或撤回。新输入、其他窗口修改和撤回阻止旧结果覆盖；未保存课表编辑转为候选，撤回后没有新反馈时不能立即重做。
- 关闭时暂停在途任务，重启恢复有效步骤。连续三次同类失败后停止，保留输入与有效结果，允许手动重试；没有本地教学模板回退。
- 状态、课程、画像与普通页面刷新只读取缓存；AI 自身保存不会重新触发学习循环。双模式六维图显示统一主控状态，不等待旧独立评分线程。

## 接口与保存

统一入口为 `/api/learning-agent/events`、`/api/learning-agent`、`/api/learning-agent/control`、`/api/learning-agent/lesson` 与 `/ws/learning-agent`。旧课堂、作答、对话和下一课接口适配到同一主控。模型调用在事务外完成，提交时检查任务、学习版本和对象版本，在短事务内保存。

任务、事件序号、课件、暂存及正式评价、撤回记录使用现有表。公开接口与备课流仅输出学生所需内容，过滤标准答案、解析、评分材料及内部工具参数。数据库结构不新增表。

建课过程的状态读取使用同一数据库快照，避免混合提交前的课程权限与提交后的任务。流式请求明确要求 JSON 对象；C 回调中的解析、取消或保存异常先中止请求并释放客户端资源，再由主控保留错误并处理重试。模型漏写或多写括号时只补齐或丢弃括号符号，不改写任何正文，补全后仍须通过 message、actions、state 结构校验；回复里混入 DSML 等工具调用标记时按结构错误反馈重试。解析失败时原样保存模型响应一并回传，让模型按具体错误自行修正。

## 当前课堂与验证

讲解、练习、小结采用三个独立聊天页面；各页独立恢复消息、草稿和滚动位置，主控仍读取同一知识点的完整学习记录。课堂交流中的追加板块与教学焦点绑定本次课时，防止内容误写到另一节课；跨页下一步提供入口，由学生点击进入。

统一课表只在学生手动请求后生成候选，确认后应用同一份结果；普通后台学习更新不能自动重新排课。

协议验收覆盖自主课程结构、六类题型、先评价后讲解、提示曝光、追问不评分、失败与重试、同题去重、一题画像、课程重排与撤回、复习日期、缓存和重启恢复。浏览器验收覆盖各页记录隔离、题目与输入布局、答案隐藏、流式反馈、草稿、停止、重试和窄屏。六维图覆盖空值、零分、学科选择、键盘、触屏及文本安全显示。

测试模型夹具用于验证接口与保存行为，不作为真实 AI 的教学能力证明。真实模型验收使用隔离档案；Linux、Sanitizer、安装包和免安装包由 GitHub CI 完成对应提交的验证。

私人数据库、缓存、截图、真实 AI 凭据和本机升级备份不进入源码与发布包。
