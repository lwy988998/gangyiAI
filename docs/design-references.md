# 本轮界面与教学实现参考

本轮沿用 C++17、Crow、SQLite、WebView2 和原生前端，现有 KaTeX 与 ECharts 随包运行。

| 项目 | 参考内容 | 本项目采用方式 |
| --- | --- | --- |
| [AILINES-AI](https://github.com/lwy988998/AILINES-AI) | 课程骨架、阶段与知识点、分步讲解和课程课件组织。 | 将课程、课时和学习材料组织在现有持久化主控中；讲义与课件以已保存的真实内容呈现。 |
| [reveal.js](https://github.com/hakimel/reveal.js) | 网页内翻页、当前页焦点、键盘操作和公式呈现的交互习惯。 | 使用本项目的内容组件提供翻页与学习焦点，复用现有公式渲染。 |
| [JSXGraph](https://github.com/jsxgraph/jsxgraph) | 参数操作、几何与函数可视化、即时观察变化。 | 采用结构化图示参数与受控绘图组件，交互在本机计算，内容与当前课程关联。 |

参考用于教学组织和交互设计，不把参考项目的能力或测试结果当作本项目已经实现的功能。实际能力与验收范围以版本说明和测试记录为准。
