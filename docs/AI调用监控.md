# 全软件 AI 调用监控

右下角的「AI 状态」在各页面实时更新。展开后直接列出全软件正在请求、接收、排队或暂停的任务，每项显示来源、用途、具体操作及累计请求次数。已完成、等待学生、失败及已停止的记录放在默认折叠的「调用历史」中，任务详情和当前课时的执行步骤也默认折叠。

「暂停全部 AI」中断正在连接、等待首字或接收内容的模型请求，并阻止新的模型请求。已经保存的有效课件、评价、输入和学习进度保留，尚未校验的中断输出不会作为完成结果。暂停开关保存在当前档案的数据目录，重启软件仍保持暂停。

「恢复全部 AI」继续暂停前尚未完成的任务。教学主控读取已保存步骤，独立请求在程序仍运行时使用保留在内存中的输入重新请求。已经完成的任务不会因为恢复而重新执行。用户单独停止的任务保持停止；软件退出会结束独立请求，历史显示其已中断。

次数从 AI 客户端的实际请求尝试处记录，包含失败后的重试和暂停后恢复时重新发出的请求。状态读取、页面刷新、本地资料读取、课件保存、获取模型列表及联网搜索不算模型推理请求。旧版本只能提供模型轮次，界面单独标明，不能将它伪装成实际请求次数。程序记录的尝试次数不等于服务商最终计费次数；已发送请求中断后仍可能产生费用。

监控覆盖统一教学主控、课程与阶段生成、课件和题目生成、作答评价、提示和错题巩固、画像评估、学习调整、导师交流、图片目标识别，以及 Windows 启动器的 AI 连接测试。调用元数据和全局暂停开关由启动器与后台服务共享，不新增数据库表，不保存提示词、模型正文、密钥或私有评分标准。

本地回归使用隔离档案与模拟服务，验证并发显示、实际次数、跨进程中断、暂停期间排队、恢复全部任务及页面订阅恢复，不调用真实收费模型。
