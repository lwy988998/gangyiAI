# 钢一定制AI v5.1.1

## 修复

- 修复 AI 回答里的列表标记被全局样式清空的问题：无序列表恢复圆点（嵌套为空心圆与方块），有序列表恢复数字编号。

## 与 v5.1.0 一致的功能

- 用户中心：侧栏导航 + 概览、我的课程、学习时间、学习画像、AI 设置五个区块；每周可学习时间从首页搬入并保持与课程计划页同步。
- AI 对话：逐字输出、Markdown 排版、KaTeX 数学公式、复制按钮、三条追问建议、停止回答与「回到最新」。
- 数据库结构不变，原有课程、进度、对话与密钥全部保留。

## 下载与升级

- 安装包：`gangyiAI-setup-v5.1.1-x64.exe`
- 免安装包：`gangyiAI-portable-v5.1.1-x64.zip`
- 校验文件：`SHA256SUMS.txt`

退出旧程序后安装到原目录即可；免安装用户完整解压后覆盖原程序目录。用户数据继续位于 `%LOCALAPPDATA%\GangyiAI\data`，密钥继续由 Windows 凭据管理器读取。
