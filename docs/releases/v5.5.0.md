# 钢一定制AI v5.5.0

课堂改为先作答，再由真实 AI 连续讲解。点击「让 AI 准备下一课」后，AI 读取最新学习记录，流式展示备课过程，全部校验并保存成功后自动进入课堂。

- 诊断、课堂互动、例题、练习、测验和复习统一显示原题、材料、选项、输入框与持续对话。选择题也能输入答案和思路，支持追问、请求解析、暂时不会、跳过、停止与重试。
- 作答前，公开接口、页面源码与备课流隐藏标准答案、评分结构和正确选项；刷新保留已经看过的讲解。
- 每轮先请求真实 AI 评价，再将原题、实际回答、评价、此前提示和学习情况交给真实 AI 流式讲解。教师根据回答与当轮偏好选择解析、提示、追问、补讲或其他适用解法。
- 未写过程时明确分析依据不足；未作答表示缺少信息，不算不会。同题多轮交流只算一道独立题，见过提示或讲解后标记受帮助作答，画像每维仍要求至少三道不同可靠题目。
- 对话、题目快照、提示、评价与模型来源保存在本机，按版本一起提交。停止、截断、空输出、结构无效或失败不产生新的可靠评价，保留原结果与学生输入。
- 下一课综合所有活跃课程的目标、实际作答、对话、可靠反馈、画像、进度、复习和共享时间预算，可正常推进、巩固、复习或切换学科；未发送文字保存为草稿，评价在途先等待处理。
- 备课依次展示调整说明、课程总览、讲解、例题、练习、测验和总结。每阶段一次真实请求，输出预算 8192、超时 60 秒，失败不自动循环重试；取消或失败留在备课页，可重试或返回。
- 重复点击、刷新、重连和多窗口订阅复用同一备课任务，事件顺序可恢复。提交前重新校验学习、课程、内容与课表版本，过期结果不能覆盖最新状态。
- 巩固课使用独立课堂任务，内容、作答、展示状态和进度独立保存，不覆盖原课堂、不增加原大纲完成节数。已展示与已作答题目保持稳定，手动课表及未保存编辑继续受预览确认保护。
- 新增统一公开题目接口与下一课任务、状态、停止、重试和流式订阅接口；旧提交与测验接口接入同一评价服务。数据库不新增表，原课程、历史作答、双模式六维画像及 AI 配置继续保留。

Windows 提供安装包、免安装包和 `SHA256SUMS.txt`。私人档案、数据库、缓存、截图和凭据不随源码或发布包上传。
