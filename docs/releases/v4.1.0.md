# 钢一定制AI v4.1.0

本次更新在 v4.0.0 个性化学习基础上补齐课堂互动、补弱复习和每周安排闭环，并统一 Windows 冷启动体验。

## 主要更新

- 课堂开始先完成 2 道诊断题；结果不明确时追加第 3 道，并按薄弱、一般、熟悉三档调整讲解。
- 每节课提供预测、复述和新情境应用三类互动，支持逐级提示、跳过、选中文字提问及可停止的流式连续追问。
- 保留 70% 测验标准且不锁住下一课；未掌握时提供短补弱，掌握后安排第 1、3、7 天复习，失败则次日再练。
- 新增可编辑周计划和待复习清单；覆盖手动安排前必须确认，课程路径调整继续受多来源客观证据门槛保护。
- Windows 冷启动统一使用光栅扫描动画；减少动画模式会直接进入首页。

## 数据兼容

旧课程、学习记录、课程快照、测验结果、聊天记录及 Windows 凭据均会保留。数据库会自动迁移并为旧课程补齐课堂标识，不删除既有进度。

## 下载

可选择安装版 `gangyiAI-setup-v4.1.0-x64.exe` 或免安装版 `gangyiAI-portable-v4.1.0-x64.zip`，并使用同页 `SHA256SUMS.txt` 校验文件。

安装包尚未签名，Windows 可能显示未知发布者提示。
