# 钢一定制AI v5.6.3

电脑版整合“资料与知识库”和现有教学质量修复，减少重复工具回执，完善实际 Token 用量统计。教学模型、思考设置、评分规则及原有功能保持现有配置。

## 本次变化

- “我的AI → 资料与知识库”管理联网检索和已保存资料，支持原文快照、按段读取、引用依据、手动选用与排除、缓存及显式刷新。资料读取、检索和模型请求分别统计；学习记录与原文快照继续保存在本机。
- 保留教学质量工作区已合并的原题、帮助经历、复练关联及评分证据修复，区分生成中的部分内容与完整结果，暂停恢复和失败重试继续保留已完成行动。
- 同一只读工具的完全相同回执可引用首次完整结果，兼容省略或显式填写默认参数；引用更长时保留原值。首次结果、行动参数、数据库原件及按需读取能力仍然完整。
- 普通与流式响应保存服务商返回的缓存命中、未命中和思考 Token。“使用情况”展示输入、输出与各项明细，并标明各自覆盖的请求数；缺失显示“未提供”，真实零值保留，缓存及思考不重复加入总量。
- 保留独立安装标识、档案、设置和 Windows 凭据管理器；数据库增量迁移前自动备份。安卓开发工作区不受影响。

## 下载与升级

- `gangyiAI-setup-v5.6.3-x64.exe`：正式版安装包，原位升级正式版。
- `gangyiAI-portable-v5.6.3-x64.zip`：正式版免安装包，完整解压后运行 `gangyiAI-launcher.exe`。
- `gangyiAI-learning-preview1-v5.6.3-x64.exe`、同名 `.zip`：现有学习增强试用版的兼容升级包，保留试用版独立档案；版本号同为 5.6.3。
- `SHA256SUMS.txt`：正式版校验值；`SHA256SUMS-learning-preview.txt`：学习增强试用版校验值。

正常升级无需先卸载。正式版与试用版的数据不会自动混合；升级前建议从托盘备份当前数据库。

## 验证口径与限制

本次使用本地模拟模型验证协议、证据保留、缺失用量、重复事件和恢复流程，不新增付费模型验收。专项回归中，一组重复工具回执消息由 1,832 缩至 993 个 UTF-8 字节；这仅代表该消息的体积变化，不能当作实际 Token、整体耗时或平均节省率。

真实模型的完整教学对照尚未完成，保留原试用成果，不声称已证明整体教学提升或固定节省比例。本机资料库页面的最终视觉验收及截图仍受工具访问限制，未通过其他渠道绕过。程序目前未进行代码签名。
