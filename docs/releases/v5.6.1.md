# 钢一定制AI v5.6.1

电脑版新增“我的AI”，位于首页导航“AI导师”旁边，作为软件控制中心和个人中心。

## 新功能

- 个人概览、AI管家、学习报告、学习计划、教学偏好、AI记忆、AI任务、使用情况、个人资料、软件设置和数据管理均提供独立页面。
- AI管家支持多个聊天的新建、重命名、搜索、归档与继续，分别保存聊天、草稿和滚动位置。
- 教学偏好和长期记忆与课程、课堂及AI导师共享；支持编辑、删除、关闭自动记忆和偏好撤回。重要操作显示影响并确认后执行，重复确认只执行一次。
- 学习报告展示真实学习记录、知识点掌握情况、六维能力、薄弱点和趋势；原画像、学习时间及统一课表入口迁入报告与计划。
- 新增前台有效学习时长与模型请求统计。Token 只显示服务商实际返回值，缺失时显示“未提供”；历史缺失的时长和快照明确提示。
- 图表使用本地打包的 Apache ECharts 6.1.0，保留许可证与 NOTICE。

## 修复与升级

- 修复请求统计写入与状态读取之间的锁等待，保持课堂先评价再讲解的调用顺序。
- 修复较矮窗口下聊天输入区布局，补齐空数据、刷新、重启和旧入口跳转处理。
- 数据库由结构版本6迁移至7，升级前自动生成 `.pre-v7.db` 备份。原课程、聊天、画像、设置与 Windows 凭据继续保留。
- 保留 Windows 原安装标识，可直接覆盖升级 v5.6.0；安卓开发工作区不受影响。

## 下载

- `gangyiAI-setup-v5.6.1-x64.exe`：Windows x64 安装包。
- `gangyiAI-portable-v5.6.1-x64.zip`：完整解压后运行 `gangyiAI-launcher.exe`。
- `SHA256SUMS.txt`：安装包和免安装包的 SHA256 校验值。

本版已通过核心测试、隔离模拟模型的页面与控制流程验收；真实服务商的教学效果仍取决于配置的模型。统计从升级后积累，历史缺失数据不会补造。程序目前未进行代码签名。
