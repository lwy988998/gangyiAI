# 钢一定制AI v5.6.6

本版以 v5.6.5（516c586）为基线，消除重复启动推荐与重复并发搜索。继续使用原有 C++、SQLite 和教学主控，不新增网关、常驻服务或第三方运行依赖。

## 改动

- 已完整完成的启动推荐，在权限、学习记录、帮助经历、偏好、资料、画像、课时、复习、备课、日期及模型配置未变化时复用。推荐归属、内容及提示版本再次校验；同版本知识点重评、薄弱点和复习到期也会使旧结果失效。
- 同一业务请求继续关联原任务与已完成步骤；新作答保持独立身份。主动刷新、重新生成和状态变化继续正常调用。
- 同一范围、服务商、端点、凭据身份、查询与参数的在途搜索共享传输。两家仍并行；单个等待者取消不影响其他等待者，全部取消才中止共享请求，明确刷新绕过共享和缓存。
- 保留原搜索有效期、排序、合并、引用及私有答案过滤。实际 HTTP 尝试与复用来源分别记录，资料保存回滚不会抹掉已发生的搜索用量。
- 在原有教学输出模板中明确示范题数组和完整反例的登记，避免漏记已经解答的示例。保持原题、真实回答、模型、思考、输出上限、评分规则及先诊断后教学的执行结构。

内部回退开关与开发验收入口见 [调用复用说明](../ai-call-reuse.md)。

## 实测与质量核对

真实搜索使用同一候选驱动的共享开关对照：两个相同并发查询关闭共享时 4 次 HTTP，开启时 2 次；随后磁盘缓存读取 0 次，明确刷新 2 次。四阶段两家均成功，返回非空资料；共享等待者得到一致结果。本轮未推算整体节省百分比。

真实教学固定相同分数题、独立错误作答、模型和资料。两版均保存原题与真实回答，诊断准确引用“分子分母分别相加”的原话，给出 10 分并注明单题证据限制，完成针对性讲解、新练习后等待学生。新练习未泄露私有答案。候选完整示范与独立新题使用不同数字，示范索引经零调用原生探针验证：后来作答已示范题时标为“示范后作答”；公开接口不含私有答案与评分标准。

首次候选曾漏记算式示例，原始结果保留；明确既有输出模板后重新验证通过。基线先前中断后从检查点恢复，没有重做有效评价。两版首次教学各 4 次实际 HTTP，基线已知 22,676 Token，修订候选 24,960 Token；该样本首次教学 Token 未下降。重开已完成任务时两版均新增 0 次 HTTP、0 Token，任务、学习记录、课时和用量逐字段不变。这证明既有任务恢复保持有效，不把它算作新机制额外节省。

本机回归覆盖重复提交、跨连接恢复、状态失效、刷新、取消、多窗口变化、评价发布顺序、帮助及复练关系。明确“再试一道”仍强制关联原题；普通自主新增练习继续按原协议处理。Windows/Linux、Sanitizer、安装与虚构档案升级恢复的最终状态，以 [PR #25](https://github.com/lwy988998/gangyiAI/pull/25) 对应提交的检查结果为准。
