# 钢一定制AI v5.0.0

## 三种能力同时生效

- 个性化算法：保留学习画像、主题掌握度、证据链、课程难度适配和下一步推荐；证据不足不虚构掌握分。
- 普通 AI 导师：最近八条对话上下文、流式回复、停止回答；完整回答保存至本机，停止或中断不写入半截回答。
- 课堂 AI：保留诊断分流、互动题、逐级提示、补弱、1／3／7 天复习、周计划、选中文字提问与流式课堂追问。
- 普通导师与每个课时分开记忆，共享同一份学习画像；继续使用现有 DeepSeek 与博查配置。

## 修复升级与打包

- 修复已为 schema 5 的旧数据库没有课堂表的问题：新增 schema 6 幂等迁移。
- 迁移前自动生成 `.pre-v6.db` 备份；旧课程、进度和对话记录继续保留。
- Windows 安装包和免安装包同时包含 `classroom.js`、`classroom.css`，并纳入发布验收。
- 移除课堂旧内联聊天提交逻辑，防止混入整门课程历史或重复绑定。
- 普通 HTTP 问答接口仍兼容旧请求，新增可选 `messages`；新增 `/ws/ask`。

## 下载与升级

- 安装包：`gangyiAI-setup-v5.0.0-x64.exe`
- 免安装包：`gangyiAI-portable-v5.0.0-x64.zip`
- 校验文件：`SHA256SUMS.txt`

退出旧程序后安装到原目录；免安装用户完整解压后覆盖原程序目录。用户课程数据继续位于 `%LOCALAPPDATA%\GangyiAI\data`，密钥继续由 Windows 凭据管理器读取。无需重新录入原配置。
