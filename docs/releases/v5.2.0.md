# 钢一定制AI v5.2.0

## 根据最新表现重排课表

- 从今天开始安排未完成课时，优先处理到期复习和薄弱知识点。本周已无可用学习日时顺延到下周，刷新或重开软件后保留安排。
- 使用页面当前选择的学习日和时长；覆盖手动安排前展示预览，确认保存同一份结果，防止不同窗口覆盖新计划。
- 重排过程与结果都有明确提示；AI 暂不可用时仍能按学习记录完成规则排课。此按钮保留原课程大纲。

## 首页 AI 学习目标推荐

- 每次启动软件后台调用一次 AI，同时生成快速规划与深度课程两组目标，兼顾继续学习、补弱和探索新方向。
- 每组五条，点击填入输入框，可修改后再生成课程。刷新、切换模式和后台服务自动重启复用本次推荐。
- 生成等待或失败时使用本机缓存或通用示例，不阻塞启动，也不重复请求。

## 最近课程与真实画像

- 首页显示最近三门课程及最新课时、进度和学习时间，点击卡片进入课程。
- 测验支持“暂时不会”，与漏答及普通错误分开记录，作为真实学习诊断反馈。
- 学习画像以易读的解释、入门起点及本地时间呈现，不展示内部证据编号。

## 下载与升级

- 安装包：`gangyiAI-setup-v5.2.0-x64.exe`
- 免安装包：`gangyiAI-portable-v5.2.0-x64.zip`
- 校验文件：`SHA256SUMS.txt`

退出旧程序后安装到原目录，或完整解压免安装包后更新程序文件。数据库结构不变，已有课程、学习进度、作答和画像继续保留；API 密钥继续由 Windows 凭据管理器保存。

发布包不包含个人课程、画像、作答、数据库、截图或密钥。推荐缓存保存在本机数据目录，不随发布包上传。
