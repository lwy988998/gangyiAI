# 钢一定制AI v5.6.4 离线候选

本次交付为可审阅的离线候选，继续使用 C++、SQLite 和现有页面架构。未创建正式标签或 Release；按用户明确要求，已在备份本机 5.6.3 程序、学习数据、设置、凭据目标状态和桌面入口后原位升级。

## 变化

- 资料库使用当前课程选择；清空课程后检索任务和手动添加保持个人范围，仅缺少控件时回退 URL。
- “使用情况”区分请求耗时与任务排队、首内容、完成耗时，缺失用量保持“未提供”；失败 HTTP 的已知 Token 仍计入。
- 统一主控按需读取教学上下文并压缩重复工具结果，保留原题、原文引用、学习证据、帮助和复练关系。离线消息字节变化不能等同真实 Token 或耗时改善。
- 开发验收入口按累计预算保留未知用量；预算写入、关闭或原子提交失败时停止后续验收，旧有效账本不能当作新结算。开发驱动及私有材料不进入包。

## 产物与使用范围

- `gangyiAI-learning-preview1-v5.6.4-x64.exe`：学习增强试用版候选安装包。
- `gangyiAI-learning-preview1-v5.6.4-x64.zip`：完整免安装候选，含全部运行库、静态资源及中文说明。
- `SHA256SUMS.txt`：这两个候选产物的 SHA256。

候选与现用学习增强试用版共用 `GangyiAI-Library-Preview` 安装、档案及凭据标识。2026-10-20 已完成本机原位升级：服务与启动器版本均为 5.6.4，启动器自检通过，学习数据库哈希未变，设置、凭据目标和桌面入口保留。升级前备份保留在用户指定项目总目录内。

安装、卸载和 5.6.3 试用版原位升级安排在 GitHub 临时 Windows runner。升级脚本先校验公开旧包，使用虚构课程、原文快照、手动选择、注册表设置及凭据，核对升级保留、产品 SQLite 备份恢复与回滚副本。该验证须以对应 CI 的实际结果为准；脚本已存在不代表已运行通过。Linux 服务、CTest、运行时接口和 Sanitizer 使用既有 CI。
