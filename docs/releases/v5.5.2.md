# 钢一定制AI v5.5.2

这一版只调整桌面端外观与窗口行为，教学、评价、画像、复习与备课逻辑与 v5.5.1 完全一致。

- 启动时打开的主窗口默认占工作区约九成并居中，不再受 1120×760 的旧上限限制，大屏上不再显得局促。
- 记住上次的窗口大小与位置：拉伸、移动后正常关闭，下次打开沿用；上次最大化关闭时下次仍以最大化打开。
- 窗口保存值落在已移除的显示器外、尺寸小于 1024×640 或超出当前显示器工作区时自动回退或收缩，不会把窗口丢到看不见的地方。
- 主窗口最小尺寸限制为 1024×640，课堂与备课页面不会被拉伸到无法使用的尺寸。
- 启动扫码动画的画幅、标题与进度条同步放大，在大窗口里保持原有视觉比例与动画时序。

提供 Windows x64 安装包、免安装包和 SHA256SUMS.txt。免安装版需完整解压，使用 gangyiAI-launcher.exe 启动。AI 功能需要自行配置模型服务；未配置或服务失败时保留有效内容，不使用固定教学模板兜底。

课程、历史作答、学习进度、双模式六维图与 AI 配置继续保留；数据库结构未变化，无需迁移。私人档案、数据库、缓存、截图与凭据不随发布上传。
