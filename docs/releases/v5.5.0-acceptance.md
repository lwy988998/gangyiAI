## 已完成的结构及服务检查

对应自动化检查位于 `tests/next_lesson_tests.cpp`、`tests/next_lesson_smoke.py`、`tests/question_dialogue_tests.cpp` 和 `tests/database_atomic_tests.cpp`。模型夹具检查请求、流式分片、版本及保存行为，不能替代上节所述的真实模型验收。

已经完成的单元及此前备课服务回归证据覆盖：

- 公开内容采用字段与路径白名单；例题材料、题干与选项保留，私有答案、解析、评分依据和未知内部字段不进入公开流。未完成的 JSON、中文分片及转义分片按公开内容提取。
- 备课调整决策与六个板块各请求一次；失败不循环重试。重复点击、相同请求重发及已有任务的订阅复用同一任务，进入已保存课堂不重新生成。
- 题目反馈按稳定题目身份去重；多轮交流仍属于同一道题。受帮助作答与可靠评价分别记录，停止、失败或不完整输出不提交新的可靠评价。
- 数据库事务检查提交与回滚。备课保存时再次校验学习、课程、内容、课表及任务版本，完整内容和就绪状态一次提交。
- 巩固课使用独立课堂任务与进度，原课堂内容和原大纲完成计数保持独立；重复完成操作幂等。
- 已提交评价在途时先等待；评价失败后把学生原文与明确的失败状态送入下一课决策。
- 中途学习版本变化使任务过期，未保存半成品课堂；取消后不创建已准备课堂。显式重试重新请求，停止或失败时保留已展示内容。

最终增量单元检查已通过。近期新增的画像在途等待、真实已展示帮助片段、连续三节推进及不同来源冲突回归，仍以最终完整回归结果为准；通过后由执行者补充准确测试结果，不在此预先标记通过。
