# 钢一定制AI v5.7.2

- 精简主要学习页面的顶部工具栏。课堂保留课名，深度课堂的全屏操作移到顶部，其余入口集中到操作菜单。减少常驻控件，为讲义与对话留出空间。
- 扩展互动实验，新增数轴、平面向量、方程等价变形和描述统计等能力。课堂可恢复探索草稿，听取老师对当前操作的解释。服务器重新计算组件结果，探索本身不计分。
- 加入试卷讲解和可核对的导入流程，改进学习资料、复习与跨课时学习记录。

Windows 资产使用「学习增强试用版」安装标识。已安装同渠道的用户可直接升级，建议先备份学习档案。免安装 ZIP 需要完整解压后运行 `gangyiAI-launcher.exe`。程序使用 WebView2，AI 教学需要可用的模型服务。

课堂与互动已进行本地工程验证。全学科的真实教学、专家与学习效果验收仍在进行。
