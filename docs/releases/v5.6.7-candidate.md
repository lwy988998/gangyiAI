# v5.6.7 整改候选

本文保留最终验收前的本地候选范围与边界。正式阶段的整改、真实短配对及发布验证见 [v5.6.7 版本说明](v5.6.7.md)；离线回归不能单独证明模型讲解质量或整体节省比例。

本次针对 2026-10-27 扫描发现的问题整改：

- 恢复数据库时通过 SQLite 正确处理 WAL 与已有连接，避免“恢复成功”后仍读旧日志。
- 选择题的底部发送和题卡提交保留同一份真实选择与说明；自由交流保持独立。
- 先练习再首次讲解时，首次任务与课时归属保持一致；未结束任务的暂停、失败和恢复仍须有效。
- 资料使用统计不再充当资料内容变化，避免误使上下文及启动推荐复用失效。
- 搜索缓存采用新协议隔离旧进程，并按刷新世代拒绝旧请求覆盖新结果。精确查询身份、有效期、排序和两家并行策略保留；升级后旧搜索缓存不直接命中，会有一次性冷启动。
- 本机 HTTP 与全部 WebSocket 统一检查 Host 和浏览器来源；启动器健康检查与关闭请求携带实际端口，保留不带 Origin 的本机原生管理调用，并以真实回环通信自测验证兼容。
- 对话支持经过校验的站内链接，继续拒绝危险协议、协议相对地址及反斜杠路径。
- 发布工作流对新建和已有 Release 都补齐附件、校验摘要，再更新公开状态和 latest；本轮只做本机模拟，不实际操作线上 Release。

保留原模型、思考设置、输出上限、评分依据、诊断后教学顺序和重试上限。不新增产品运行服务或第三方运行依赖。

用户已明确要求将本机升级为最新版本。升级前备份程序、档案和设置，升级后核对版本、桌面入口、档案保留和无密钥泄露。安装验证期间 AI 保持暂停，避免自动发起付费请求；真实教学验收和 GitHub 正式发布另行记录。
