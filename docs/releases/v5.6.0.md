# v5.6.0：钢一研习工作台与统一 AI 课堂

本版采用用户选定的 C「钢一研习工作台」，保留深色配色和校徽，整理课程入口与课堂布局。

## 界面与学习流程

- 首页恢复左侧品牌与目标输入、右侧雷达；保留图片上传、AI 推荐、最近三门课程。AI 建议默认呈现一句，完整说明可展开。
- 我的课程分为课程和画像两个页签；统一学习安排集中在课程页，画像与学习时间集中在画像页。
- 我的课程进入全部课程列表，当前课程恢复最近实际访问的有效课程总览；刷新、重启及删除后保持有效入口。
- 课程页突出目标、进度和阶段；资料、作品任务、知识结构与路线说明默认折叠。课程内部提供阶段和知识点目录，窄屏可展开。
- 统一课堂分为讲解、练习、小结。讲解聚焦当前段，练习一次呈现一道题，历史内容和交流可以回看。
- 桌面目录可收起，窄屏使用抽屉；顶部提供课程位置、三页切换和上下节，悬浮入口集中 AI 状态与控制。备课页沿用相同风格，展示真实状态与预览，支持暂停、恢复和重试。

## AI 与记录

- 三页共用稳定课时、板块和题目标识；教学焦点由 AI 保存，刷新和切页复用内容与任务。
- 真实作答先评价再讲解，纯追问不新增评分；示范例题作为讲解，不产生新的学生评分。
- 小结读取已有检查点、评价、历史记录和资料。完成与下一课由 AI 根据真实证据决定。
- 保留旧课堂链接、课程索引、备课和复习参数，适配历史概览、示范、检查点及测验成绩。
- 草稿迁移只执行一次；暂停、恢复、同次重试和撤回保留有效记录。取消订阅后的迟到响应不会覆盖当前课堂或记录未呈现内容。
- 根据回答追加的新选择题自动接到当前课堂页，保留题目标识与真实选项，兼容历史已生成但未激活的问题。
- 统一课表只在手动请求后生成候选；确认应用原候选，取消保留原安排，过期候选不能覆盖新修改。
- 修复备课证据数组被当作对象读取的异常；402 和鉴权错误立即停止，可恢复错误最多连续三次，已有有效动作保留。
- 导师停止后会收到取消终态并恢复发送；停止按钮放在输入框旁，成功回答不会被关闭连接后的迟到错误覆盖。
- 排课主控读取真实任务目录及本机日期，区分大纲任务、已备课课时与复习标识；候选日期范围跟随实际安排。
- 删除课程后，已删除的最近 AI 任务回到空闲状态；恢复备份或重启服务时，即使端口相同，也重新读取页面。
- 保护延迟 HTTP 响应的连接生命周期，避免完成回调清空时提前释放连接。

## 验证与交付

Windows 本地构建与 20 项测试通过；浏览器和 Windows MCP 已验证课堂操作、目录、草稿、恢复、双屏和窄屏布局。隔离档案的真实 AI 教学流程与真实数据副本完整性核验通过。补测包括真实图片识别、模型列表与接口连接、联网检索连接、导师停止及连续提问、画像更新、路线预览、课程删除和对话清空，以及桌面备份、损坏文件拒绝、恢复和诊断报告。

安装包和免安装包在本地生成并核对 SHA256，已备份安装本机试用。持续集成结果以对应提交的 GitHub 检查为准。

沿用原生前端和既有数据库表。课程混合调度与启动调用耗时维持原定范围。本说明用于准备发布；正式发布须在用户确认试用满意后执行。
