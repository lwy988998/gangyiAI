# 钢一定制AI v5.3.0

首页和用户中心现在提供真正的六维雷达图，可切换「学科画像」与「学习能力」。采用正向六边形网格、薄荷绿轮廓与渐变填色，支持键盘和触屏查看每个维度的依据、建议及本地更新时间。

- 学科画像支持高中九科任选六科，默认语文、数学、英语、物理、化学、生物；选择及显示模式保存在本机，刷新、重新启动及不同窗口共用。
- 学习能力综合全部课程，独立评估知识记忆、概念理解、方法应用、逻辑推理、表达说明和综合迁移。
- 两张图的正式评分和建议由已配置的真实 AI 评估。新作答保存题目快照和稳定标识，每项评分需要至少三道不同题目的可靠反馈；漏答、跳过和评价失败不作为有效证据，重复题不能凑够门槛。
- 旧记录继续保留；缺少原题、无法可靠对应的历史记录不会用于推断学习能力。
- 无数据显示「待评估」，真实零分显示「入门起点」。部分维度只画有效点，六维全部有效才填充完整区域。
- 新作答自动触发后台评估；切换、选学科和页面读取不会增加评估调用。保存前核验证据版本，避免旧请求覆盖新记录。
- AI 失败时保留上次真实画像，提示等待更新；同一失败版本不反复请求，可通过「更新画像」手动重试。
- 调整画像与启动推荐的输出额度，兼容将推理过程计入额度的模型，避免推理用完额度后返回空结果。
- 保留 v5.2.0 的课程重排、最近三门课程、卡片跳转、「暂时不会」及每次启动一次的首页 AI 推荐。

无需新增数据库表。课程、作答、画像、显示偏好和 AI 配置继续保存在本机；安装包不包含个人档案、测试截图、缓存或密钥。

Windows 提供安装包和免安装包，请使用 `SHA256SUMS.txt` 核验下载文件。源码包含虚构数据自动化测试，覆盖后端证据校验、失败保留、版本冲突、重启保存以及桌面、键盘和触屏交互。
