# 钢一定制AI v5.1.0

## 用户中心

- 「我的课程」升级为用户中心：左侧栏导航 + 右侧内容，手机端折叠成顶部标签条。
- 五个区块：概览（全部课程、总体完成度、已完成节数、待复习及清单）、我的课程、学习时间、学习画像、AI 设置。
- 每张课程卡片显示完成节数与进度条，有待复习时标出数量。
- 学习画像展示学科画像与主题掌握度；证据不足时显示「数据不足」，不编造分数。
- AI 设置保留接口配置入口，并补充本机数据与密钥存放位置说明。

## 首页调整

- 移除首页的「每周可学习时间」，统一在用户中心编辑；课程计划页仍可调整，两边自动同步。
- 首页保留学习画像雷达与待复习区块。

## AI 对话呈现

- 回答改为逐字平滑输出，等待首字时显示「正在思考」动效，末尾显示光标。
- 支持标题、加粗、列表、引用、行内代码、代码块与链接排版。
- 支持数学公式（`$...$`、`$$...$$`、`\(...\)`、`\[...\]`），公式引擎随安装包发布，断网也能显示。
- 回答结束后可一键复制，并给出三条可点击的追问建议；建议生成失败时使用固定建议。
- 自动跟随最新内容，向上翻看时暂停跟随并显示「回到最新」。
- 停止回答改为等服务端确认结束，避免刚提交就停止时丢失事件。
- 所有模型输出先转义再排版，链接只允许 http/https。

## 接口与兼容

- 新增 `POST /api/ask/suggestions`：根据上一轮问答返回三条追问建议，失败返回空数组。
- 新增静态资源：`/chat-render.js`、`/user-center.js`、`/vendor/katex/*`。
- `/api/ask`、`/ws/ask`、`/ws/classroom` 与课堂各接口保持兼容。
- 数据库结构不变，无需迁移；原有课程、进度、对话与密钥全部保留。

## 下载与升级

- 安装包：`gangyiAI-setup-v5.1.0-x64.exe`
- 免安装包：`gangyiAI-portable-v5.1.0-x64.zip`
- 校验文件：`SHA256SUMS.txt`

退出旧程序后安装到原目录；免安装用户完整解压后覆盖原程序目录。用户数据继续位于 `%LOCALAPPDATA%\GangyiAI\data`，密钥继续由 Windows 凭据管理器读取，无需重新配置。
