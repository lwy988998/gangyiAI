# 钢一定制AI v5.6.7

本版修复备份恢复、教学输入与任务归属、资料复用、搜索刷新竞争、本机接口来源校验和发布重跑问题，并补充真实验收发现的数学术语与评分边界要求。继续使用现有 C++、SQLite 和教学主控，不新增网关、常驻服务或第三方运行依赖。

## 改动

- 数据库恢复使用 SQLite 锁与原生备份事务，保存回退副本，正确处理 WAL 残留；活跃连接导致无法安全恢复时拒绝继续。
- 题卡、底部发送和 Enter 保留同一份选择与说明，普通交流保持独立；先练习后首次讲解正确关联课时和任务，保留失败、暂停、取消及恢复行为。
- 纯资料用量统计不再使内容复用失效。搜索使用跨进程刷新世代和文件锁，防止慢旧请求覆盖主动刷新结果；保留精确身份、有效期、两家并行、排序、合并与引用规则。
- 本机 HTTP 和全部 WebSocket 统一检查 Host 与浏览器来源，启动器健康检查和退出请求携带实际端口；保留原生管理调用。
- 对话支持安全站内链接，继续拒绝危险协议、双斜杠、反斜杠及异常编码路径。
- 新建或已有 Release 均先补齐并验证附件，再更新公开状态和 latest；上传或摘要校验失败时保留草稿。
- 诊断反馈、讲解和示范共用准确性要求：明确整体等分的份数与分数单位，同分母加法保持分母不变；题目未要求最小公分母时，认可正确的其它公倍数和等价解法。失败轮的讲解不当成已展示，恢复依据成功回执继续。
- 从同版本离线候选升级时清理候选标识文件，学习档案、设置和凭据继续保留。

模型、思考设置、输出上限、评分尺度、证据规则及先诊断后教学结构保持不变。已有学习记录不批量改写；新提示版本参与复用检查。搜索缓存使用 `dual-v2` 隔离旧进程，首次使用旧查询可能需要重新检索。

## 验收及实际范围

离线回归覆盖 WAL 恢复、重复提交、并发及跨进程搜索、刷新与取消、多窗口变化、任务绑定、资料失效、链接、来源防护和发布失败恢复。Windows 完整37项 CTest，以及 Windows/Linux、Sanitizer、浏览器、安装与虚构档案升级恢复由版本标签流水线执行，全部通过后才正式发布。

真实教学使用相同模型、偏好、原题与真实输入快照，与 v5.6.5（`516c586`）形成短配对：错误作答均按原话诊断，给出0分并限定单题证据；候选完成针对性引导后等待学生，实际展示内容未再出现已发现的分母定义或同分母运算错误。候选对公分母的引导题接受其它合法公倍数。另以独立正确作答验证使用24通分，完整运行后获得100分，没有因未使用最小公倍数而扣分。

基线短案例实际3次模型HTTP、19,571 Token，含初次失败及原任务恢复；最终候选实际3次、16,477 Token，含被拒绝输出与正常重试。两版重复提交及重开已完成任务均为0次新增模型回调和HTTP，实际档案逐表不变，公开视图不含私有答案。这证明复用正确，不能算成新机制额外节省。

真实双搜索的两个相同并发查询合计2次HTTP，后续磁盘缓存0次，主动刷新2次；两家均返回有效资料，并发等待者结果一致。搜索模块与最终发布源码一致。

早期真实复测发现的过窄评分标准和错误表述均保留原始记录，整改后的版本另行重测；失败、重试和未知用量继续计入累计预算。本轮不推算整体节省比例，也不将前缀缓存收益当成请求次数减少。

本轮只覆盖一组短教学配对和等价解专项，不代表原六教学案例、三类核心流程、全部学科或长期学习效果已完成真实验收。质量审阅由编码助手针对真实输出完成，不是人工专家评审。

## 安装与发布文件

安装包为 `gangyiAI-learning-preview1-v5.6.7-x64.exe`，免安装包为同名 ZIP；沿用 `GangyiAI-Library-Preview` 安装与档案标识，支持原位升级。升级前备份程序、学习档案和设置，升级后核对版本、桌面入口及数据保留。

发布附件仅包含安装包、免安装包和 `SHA256SUMS.txt`。开发测试入口、测试档案、日志、预算账本、密钥及真实学习数据不进入发布包或附件。内部复用关闭开关见[调用复用说明](https://github.com/lwy988998/gangyiAI/blob/v5.6.7/docs/ai-call-reuse.md)。
