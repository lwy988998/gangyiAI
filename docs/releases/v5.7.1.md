# 钢一定制AI v5.7.1

本说明记录 v5.7.1 功能分支的改动。当前提交尚未生成 v5.7.1 安装包或 GitHub Release；本次版本号更新未运行构建和测试。

## 改动

- 增加 AI 任务执行过程追踪，显示阶段、状态和事件历史，并支持暂停、恢复、取消与失败重试。
- 增加按课时隔离并保存的独立聊天，支持流式回复、联网设置和会话清理。
- 深度课程页面展示备课和聊天状态；请求失败时提供恢复入口，并保留已保存内容。
- 改进 AI 状态面板的轮询更新，避免重复播报相同内容；操作失败时在当前任务轨迹中说明状态。
- 将应用、CMake 工程和 Windows 安装器版本号更新为 5.7.1，并补充安装说明。

## 发布状态

- 版本源码位于功能分支 `feat/agent-run-visibility`。
- v5.7.1 的构建、自动化检查、安装升级核验和发布附件尚待完成。
- 最近的公开版本仍为 [v5.7.0](https://github.com/lwy988998/gangyiAI/releases/tag/v5.7.0)。
