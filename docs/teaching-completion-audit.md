# 教学优化目标核对

本机已更新独立电脑版教学试用版，现有档案保留。功能和协议回归已通过，但原目标尚未完成：最终版本的6案例完整真实模型对照、18案例扩展和整体教学改善结论缺少有效证据。

| 原目标 | 当前证据与结论 |
|---|---|
| 共用机制覆盖不同课程，教法由AI根据回答和偏好选择 | 共用C++主控与原接口已实现，未增加固定题数、难度或通过门槛；跨三类课程的真实效果尚未证明。 |
| 具体诊断、回答依据、证据不足先澄清 | 核心回归验证原话引用、非空诊断、澄清时不给可靠分数，课堂和报告可查看诊断；语义准确性仍待真实对照。 |
| 普通讲解、本题提示、完整示范与实际展示分别记录 | 板块、回复和评价反馈按展示记录；另一题的完整示范追加可见题目快照，复做同一快照计为示范后作答。协议与隔离回归通过，模型声明是否准确仍待检查。 |
| 历史帮助无法确定时明确标记 | 旧对话、缺少反馈类型和部分展示保留unknown；不通过猜测补写旧示范题快照。 |
| 给一点提示、看示范、再试一道、换一种讲法；保留草稿 | 真实浏览器回归验证请求类型、题目关联、不评分、草稿与选项、刷新恢复和窄屏。 |
| 关联新题、独立复练、回答和帮助报告、继续巩固 | 保存关联与独立题目快照，报告展示真实输入和帮助；核心及浏览器回归通过。模型是否安排恰当的新题、避免语义上重复已示范题仍未验收。 |
| 复用学习事件、课堂、报告、JSON与版本校验，评分材料私有 | 沿用现有接口和SQLite/JSON，追加字段；原题、示范快照、展示身份及私有字段过滤已回归。 |

## 当前验收限制

用户确认的开发验收总上限为100,000 Token，已用76,192，剩23,808，未知用量预留为0。当前调用仍保留请求前的输入字节上界、8,192输出上限和一次SDK兼容重试预留。最新课堂夹具中的最小诊断请求预留仍高于剩余额度，因此不能继续按当前验收参数调用模型；这不是正常上课的调用额度限制。

不重置已用额度，不把预算停止、协议错误或免费夹具算为完整教学验收。继续真实对照需要调整验收预算或明确调整验收方式；调整之后仍须保留同模型、人核标准、实际用量和完整多轮证据。
