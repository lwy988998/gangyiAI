# AI 调用复用与降本

本轮以 v5.6.5（516c586）为基线，在现有 C++、SQLite 和持久化主控内消除重复消耗。模型、思考设置、诊断后再教学的顺序、评分依据、讲解要求、双搜索排序与引用校验均沿用原规则。

## 复用范围

- 启动推荐只在原启动任务完整成功、推荐归属与内容仍一致、完整状态签名相同时复用。签名包括授权范围、学习证据、偏好和记忆、资料、画像、课时、复习、备课状态、日期及模型配置；首次升级没有新签名的旧推荐照常更新。
- 复用原任务及已保存操作，不重新播放写动作。新启动请求登记为原任务的请求别名；状态变化后重试同一请求仍返回原任务，修改同一请求的内容仍拒绝。
- 新回答、新尝试、主动要求重新生成继续走原教学流程。同一文字不代表同一次作答。
- 相同范围、服务商、端点、凭据身份、查询、参数和缓存目录的在途搜索共享结果。两家仍并行，现有缓存有效期不变；显式刷新绕过缓存及在途共享。
- 单个等待者取消只退出自己；全部取消后中止共享工作。缓存提交与最后一次取消串行，错误和未完成结果不进入成功缓存。

## 观察与回退

任务状态增加可选的 `reusedFromTaskId`、`reuseReason` 和 `reuseCount`。搜索分家回执增加 `shared` 与 `reuseReason`，实际 HTTP 尝试只归入一个回执，搜索用量先于来源内容保存单独落账。历史记录缺少的新字段按原样保留。

服务商前缀缓存仍是一次模型请求，缓存命中 Token 不从总量再次扣除。固定系统说明、阶段工具顺序和 JSON 序列化沿用现有稳定格式；没有通过删减原题、回答、帮助或评分证据换取节省。

内部回退开关：`GANGYI_AGENT_STARTUP_REUSE=0` 关闭启动状态复用，`GANGYI_SEARCH_SINGLEFLIGHT=0` 关闭搜索在途共享。既有请求幂等、检查点、版本校验、全局暂停和已完成任务恢复继续生效。

## 验证规则

本机夹具覆盖跨连接恢复、状态与模型变化、请求别名冲突、并发双搜索、取消、强制刷新、范围隔离、失败恢复和搜索预算停止。夹具只能证明机制，不代表真实教学能力或平均节省率。

真实教学采用两版相同输入、模型和冻结资料，完成一次“分数作答诊断→针对性教学→等待学生”的配对并逐轮审阅。开发驱动默认只允许本机模拟服务；外网需要明确本轮授权文件、冻结模型地址、原账本校验及独立共享累计账本。两版教学驱动在传输前阻止新增搜索，避免资料变化及隐含搜索消耗；真实双搜索单独验收。

模型累计上限 1,000,000 Token，起始已知用量 839,528、未知预留 72,075，可分配 88,397。搜索累计上限 20 次，起始已用 6 次。搜索开发预算通过 `GANGYI_EVAL_SEARCH_BUDGET_FILE` 绑定，Windows 原生发送前持久记账，支持进程间锁；未知请求不退款。正常上课不使用这些开发额度限制。

原始账本、凭据、实际教学记录及对照材料不提交到仓库或打包。验收预算不足或质量不通过时保留候选与报告，不发布或替换现有安装。完整六教学案例与三类核心流程仍单独记录，不能用本轮短案例替代。
