# v5.5.1：真实 AI 教学主控验收清单

本版本的目标是由真实 AI 决定学习内容、方式、题量、评价、课程调整、画像与复习。以下清单用于逐项验收，不能以局部测试代替完整交付。

## 已实现的基础

- [x] 主控可读取工具结果后继续请求模型，不限制每日次数或固定任务轮数。
- [x] 任务与行动保存到现有数据表，重复请求不重复执行。
- [x] 普通状态读取不调用模型；教师回复不构成新的学生学习事件。
- [x] 模型分片按公开字段展示，隐藏题目答案、评分标准和内部行动参数。
- [x] 源码提供隔离测试，覆盖 Unicode、访问范围、失败停止、事务回滚和多步调用。
- [x] 主控工具实际写入目标、共享预算、手动课表及两组推荐；版本冲突时不覆盖。
- [x] 目标与课表保存前后内容，可撤回且阻止无新反馈时立即重做；未保存课表草稿转为候选保存。
- [x] AI 可选择课件板块数量和顺序，后台保存原题、标准与真实输入；公开接口只返回题干和学生所需文字。
- [x] 已接入主控读取、提交、控制、课时读取与流式订阅接口，并提供独立课堂、备课页面。

当前状态：Windows 完整服务已编译，核心工具测试已经覆盖实际写入与撤回。浏览器协议模拟验收发现旧画像后台保存会改变学习版本，已修正触发链，正在复验；尚不能作为真实模型验收或正式发布通过的证据。

## 基础接口约定

主控任务包含来源范围、学习版本、请求标识、已完成行动及公开事件序列。read_context 和 read_history 提供真实记录；新增教学工具采用两阶段执行：模型调用与准备在事务外完成，版本检查与数据库提交在短事务中完成。

模型输出包含学生文字、结构化行动和继续／等待学生／完成状态。公开流只提取学生文字和合法教学板块中的题干或正文；完整内容与行动只有在真实模型输出完整、结构合法、版本匹配后提交。

测试使用虚构课程和模型协议模拟，不读取真实档案或凭据。正式 AI 验收应使用独立档案，并记录模型来源、调用顺序和实际工具结果。
