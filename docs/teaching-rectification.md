# 教学准确性、原卡片定位与传输完整性整改

本次候选针对实际界面体验及失败记录整改。模型、思考设置、输出上限、评分依据、先诊断后教学和既有重试上限保持原样。本文记录实现及验收边界，不代表完整真实教学已经通过。

## 诊断反馈与讲解使用同一准确性约束

诊断阶段会重新构造消息，因此普通教学与诊断提示共用同一准确性要求，并放在工具目录之前，覆盖评价反馈和后续教学。要求准确区分定义与推导，同一事实在反馈、讲解、示范中保持一致。

分数的规则示例是：分母表示把同一整体平均分成的份数，每份相当于整体的 1/分母。历史已展示内容如需纠错，新增更正说明，保留原文、原题、真实作答和评分证据；不通过数据库字符串替换改写历史。

对应提示版本进入启动复用指纹，每次请求的活动记录保留提示版本。旧任务仍按其原身份读取，不把旧结果当作新提示的真实验收。

## 保存位置由程序回执确定

`append_section` 成功回执新增可选字段 `view`、`href`，保留原 `sectionId`。公开课时板块及时间线使用同一归属计算：练习任务中的即时补讲仍归练习页，小结仍归小结页。旧回执没有新字段时，从原任务恢复位置，读取不回写历史。

示例：练习中的补讲返回 `/practice?lessonId=...&sectionId=...`，教师依据该回执说明位置。界面的“直达此段”和下一步入口定位原卡片；归档中的内容会展开，显式卡片定位优先于旧滚动位置。跨页跳转保留页面草稿及复习上下文。

读取已保存卡片不启动首次讲解模型请求；普通课堂入口继续使用原来的开课流程。链接不能扩大课时权限，也不把点击、浏览或定位当成学生掌握证据。

## 流式接收与错误诊断

SSE 接收层拒绝坏数据帧、错误帧结构、非正常结束原因及终态后的新正文。合法尾帧即使没有换行也要解析；`stop` 同帧的正文与随后合法用量帧继续接收。截断状态不能被后续结束标记覆盖。

合法 SSE 中的决策正文逐字保留，交给主控完整校验；不自动补齐括号来执行动作。结构失败保存正文长度、流式拼装是否一致、解析错误字节及提示版本等非正文诊断，不发布坏文字、不应用坏动作。恢复继续使用已保存诊断，完成后只发布一次评价。

异常说明中的解析摘录可能包含被截半的 UTF-8 字符；仅在序列化错误记录时替换坏字节，防止记录失败造成主控异常退出。此处理不修改学生输入、模型决策正文或动作，也不把失败转为成功。

网络错误追加 `transportDiagnostic`，只包含固定错误码、阶段、连接里程碑、TLS 后端及验证状态等白名单字段，不包含端点、代理地址、请求头或凭据。错误分类、重试资格和 TLS 验证策略保持原样。阶段是观察结果，不能单独用来认定代理或服务商就是根因。

## 回归与发布边界

- 原生主控回归覆盖两类坏决策、暂存诊断恢复、单次评价、真实板块位置、旧回执兼容、权限和私有答案过滤。
- AI 客户端回归覆盖本机拒连、TLS 握手失败、等待响应超时、诊断脱敏，以及坏帧、终态、尾帧和截断边界。
- `tests/section_navigation_browser_smoke.py` 用生产课堂主体、样式和脚本验证真实滚动、跨页、小结、窄屏、草稿与选项恢复；仅连接本机夹具，不提交教学请求。
- Windows CI 运行新增浏览器专项，Windows/Linux 原生回归继续使用现有 CTest；不增加产品运行依赖。

离线回归与连通性检查不能证明真实教学措辞必然正确，也不能替代原六案例及三类核心流程的同配置真实对照。必要真实复测未完成时保留候选和报告，不发布补丁、不替换本机程序；预算继续累计，失败、重试和未知用量均保留。
