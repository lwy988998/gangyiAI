# 教学主控调用减量与本机更新

本轮保留当前 `deepseek-flash` 模型，减少每轮重复发送的上下文，继续使用 C++、SQLite、原生课堂和完整学习档案。用户已将开发验收累计总预算从10万调整为100万 Token，此前76,192继续计入；它不限制正常上课的题量或调用次数。

## 改了什么

- 作答诊断阶段只提供评价和追问分类工具、原题标准、实际回答、帮助证据、偏好及近期相关反馈，不再附带整套备课和软件管理说明。
- 课堂阶段直接提供当前题、焦点和板块索引；其他课文按需读取，可用 `read_lesson.sectionIds` 选择板块。精简发送副本，不改写完整档案。
- 同一任务中完全相同的只读工具结果只发送一次。报错反复附带的相同成功结果改为引用已发送的结果，动作参数、首次凭据、不同版本和错误原文保留，完整档案不变。
- 近期反馈聚焦当前课程，完整历史、大纲与跨课程安排仍可由模型通过原接口读取。原题、实际帮助全文及教学偏好不被截断。
- 阅读材料纳入新题身份；保留旧导入标识，重复原题不能充当独立复练。材料变化后的新题和同题回看分别判断帮助。
- 从真实对照中发现评价卡片直接给出本题解法时，原有展示记录没有计入该帮助。新版评价补充反馈类型，并在课堂或报告实际显示后关联原题；反馈只显示一部分时保留不确定性。保存展示不增加模型请求，也不改变先前作答状态。
- 完整示范另一题时，另外保存可见题目快照，防止以后复做它仍被当成独立作答。原题只接受相关讲解，不因此串用另一题的帮助；只求小提示的请求不允许附带完整示范题。
- 本课已实际展示的示范题索引提供给AI，包含题目快照、来源和是否完整展示；安排新题时也能看到其他题的示范，不需要为查看它们重复读取整课。精确题目帮助标签与理解结论分开，语义上重复已示范题仍需AI判断。
- 每笔实际HTTP请求采用独立用量标识，任务计数重建后也不会覆盖旧统计；开发预算同时识别旧版本同ID记录的更新。验收逐轮保存检查点，恢复已完成步骤不重新调用模型。

## 实际测量

优化前基准为本轮减量前的教学候选，包含已经完成的诊断和帮助机制。两边运行同一个分数案例、相同6轮学生输入和固定教师夹具，主控调用均为10次，收费请求0次。

| 指标 | 减量前 | 示范题关联修正版 | 降幅 |
|---|---:|---:|---:|
| 6轮课堂总输入 UTF-8 字节 | 216,142 | 144,579 | 33.11% |
| 作答诊断阶段总输入 UTF-8 字节 | 82,475 | 22,048 | 73.27% |

上一轮真实 Token 计量使用当前模型，对两份实际主控提示分别请求一次，各限制输出1 Token；同一首轮诊断输入从3,666降至852 Token，减少76.76%。这两次是输入计量，不作教学或掌握评价。新增反馈类型和实际展示证据后的版本只进行了免费字节回测，未重复付费计量。字节降幅不冒充整个课堂的 Token 降幅，输入 Token 降幅也不等同账单降幅；本轮未取得费用金额。

压缩后的提示在首次英语案例中暴露了 `diagnosis` 放错位置及空 `uncertainty` 的协议问题。已把参数位置和非空要求补进工具说明；随后仅用1次真实英语诊断请求复核，诊断动作通过原题、原话引用与字段校验，实际使用1,381 Token。由于教学轮被主动限次，该次未发布为掌握证据，不能当成完整教学效果通过。

## 验收预算与限制

2026-10-14，用户明确将本轮累计总上限调整为 **1,000,000 Token**，不是追加额度。当前已核实 **839,528 Token**，另保留 **72,075 Token** 未知请求上界，可分配额度为 **88,397 Token**。共127笔实际HTTP请求，125笔取得用量，2笔未知；旧预算账本路径保留，未归零另起账本。之前的探索阶段用量在验收报告单列。

新的完整双版配对目前只有分数案例：v5.6.1为164,990 Token、203秒，6126184候选为159,229 Token、286.9秒。实际Token仅少3.49%，耗时增加41.33%；不能以免费字节降幅代替整课实际收益。英语候选在执行器中断后复制档案恢复，但最后教学轮仍失败；知识技能候选缺少讲解帮助类型并发生JSON结构错误，基线受到请求前预算保护停止。6个代表案例及18案例验收均未完成。

按真实分数候选的最终任务历史重放，新增报错凭据引用将历史从68,587减少到44,561 UTF-8字节，局部降幅35.03%，收费请求0次。这不包括全部模型调用的上下文，也不等于Token或费用降幅。后续已补齐讲解工具的必填参数说明与展示示范索引，完整真实复测尚未证明。

恢复时发现旧用量标识覆盖了3笔同任务记录。原始隔离档案保留，已根据真实响应补计15,993 Token；2笔未取得用量的请求仍保持预留。修复后的独立标识、旧ID更新结算、未知预留与超额拦截均有免费回归，未猜测未知用量为零。

以下为调整预算之前的历史记录，不是当前剩余额度：

用户确认“先限10万 Token，优先验证6个代表案例”。两版对照共21次HTTP请求，实际用量70,291 Token；另有1次诊断协议复核1,381 Token、2次输入计量4,520 Token，合计 **76,192 Token**。上述用量全部由服务返回，未取得用量的请求会保留未知状态和预留额度。

请求前按输入字节上界、输出上限和一次SDK兼容重试预留额度；结束后用实际HTTP用量结算。剩余额度不足以保守预留下次请求时就停止，不重置预算继续跑。6案例均保留了记录，多轮流程尚未完整完成；没有把预算停止、协议失败或待发布评价算作有效掌握。18案例和整体教学改善仍待后续验收。

完整核心回归、课堂浏览器回归和安装验收结果见 [教学验收报告](D:/gangyiAI-teaching/docs/teaching-acceptance.md)。18:43本机更新的是报错凭据引用与独立用量标识版；之后的示范题索引和工具说明修正交付源码，由协同整合统一打包与安装，不冒充已安装。正式版本仍待教学验收后确定。
