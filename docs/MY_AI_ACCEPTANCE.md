# 我的AI电脑版验收报告

版本：v5.6.1 电脑版。基线：GitHub v5.6.0 标签。实现使用独立工作区，安卓工作区未参与本次修改。

## 已通过

- 24项C++、JavaScript与接口核心检查全部通过。
- 我的AI浏览器验收通过9组场景：真实工具协议执行、重复请求幂等、聊天隔离、记忆来源与删除、流式用量帧、用量选项兼容重试、11页面加载、较矮窗口输入区、刷新与进程重启恢复、旧入口迁移。
- 原有课堂浏览器检查通过：内容定位、分题草稿、固定输入、卡片作答、暂停恢复、评价顺序和历史回看。
- 六维雷达通过空画像、部分/完整六维、真实零分、学科选择、键盘/触屏及文本安全检查。
- 页面就绪与启动检查通过，未出现JavaScript或HTTP资源错误。
- Windows启动器自检退出码0，安装包已由Inno Setup成功编译。
- 数据库6→7迁移、迁移备份、原数据保留、前台计时与多窗口去重通过。

## 验证范围

我的AI专项验收使用10次模拟请求，收费模型请求0次。真实模型教学效果尚未验收；本机Windows数据恢复与AI配置操作沿用现有原生流程。安装器由 Inno Setup 编译，发布验收在 GitHub Actions 隔离账户执行安装、卸载及档案保留检查。

正式构建保留原安装标识、数据目录、注册表、凭据和启动互斥锁。可选试用构建使用独立标识。
