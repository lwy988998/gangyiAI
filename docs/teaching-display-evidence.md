# 教学帮助实际展示边界

长讲解或示范原先只要卡片与视区相交，就会记录整段内容已展示。现在按正文累计可见范围，区分曾显示与完整显示；标题、边缘和只显示一部分的正文不能证明完整示范。

- 板块沿用版本展示回执，追加 `sections[].complete`；消息沿用展示游标和片段序号，追加 `completeSequences`。不更改已有接口与课时权限。
- 完整覆盖正文前，本题提示或示范记为 `unknown`、`partial=true`；普通概念仍作为相关讲解，不被改成本题提示。示范题索引只有完整展示后才标为完整。
- 旧客户端的版本或游标继续接受；没有展示程度依据的旧记录不推断完整。相同版本或相同消息片段的完整回执保留，刷新后的部分回执不能降级它。
- 直接进入练习、小结时可以没有讲解焦点，仍会完成初始定位并开始累计滚动。修复了此时一直跳过滚动检查、只留下首尾范围的问题。
- 展示回执只保存证据，不评分、不增加模型请求，也不代替AI对理解和复练的判断。评分材料仍通过既有私有边界保护。
