# Windows 10/11 发布前人工验收

- 在未安装 CMake、编译器、Visual Studio、Python 和 Node.js 的 Windows 10 x64 虚拟机安装。
- 在同样干净的 Windows 11 x64 虚拟机安装。
- 验证中文用户名、非管理员账户、默认安装目录和桌面快捷方式。
- 首次配置 DeepSeek、OpenAI 和自定义接口，验证获取模型、测试连接及手工模型回退。
- 结束 `gangyiAI.exe`，确认启动器按 2、5、15 秒恢复，连续失败三次后停止。
- 从托盘查看日志、打开数据目录、导出诊断报告，确认报告不含 API Key 和课程正文。
- 备份数据库、恢复备份、尝试恢复损坏文件，并确认失败时原数据可回滚。
- 解压免安装 ZIP 后直接运行，确认数据仍写入 `%LOCALAPPDATA%\GangyiAI`。
- 执行升级安装和卸载，确认设置与课程数据库保留。
- 核对安装程序、两个 EXE、托盘、快捷方式和网页校徽图标。
- 核对草稿 Release 的标签、提交、附件名称、大小和 SHA256 后再公开。
