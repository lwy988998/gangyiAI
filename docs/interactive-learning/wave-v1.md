# 简谐横波探索 v1

`wave_lab` 表示向 x 正方向传播的理想简谐横波。可调整振幅 A、设定波速 v、周期 T、时刻 t 和固定质点的平衡位置 x；程序用 `λ=vT`、`f=1/T` 和 `y(x,t)=A sin[2π(x/(vT)−t/T)]` 计算当前图形。固定质点只有竖直位移，振动速度为对时间求导的 `−2πA/T cos[2π(x/(vT)−t/T)]`，与传播速度区分。

公式及运动方向依据 [OpenStax University Physics Volume 1，16.2 Mathematics of Waves](https://openstax.org/books/university-physics-volume-1/pages/16-2-mathematics-of-waves)（2026-11-28 核对）；本组件独立编写公式计算和 SVG 绘图，没有复制教材插图或引入新依赖。

- A 为 0—2 m，步长 0.5；v 为 1—5 m/s 的整数；T 为 1—4 s，步长 0.5；t 为 0—8 s，步长 0.25；固定质点位置为 0—12 m，步长 0.5。
- 控制波速不变时，改变周期使波长随之改变；改变振幅不改变模型的设定波速。波速控件直接修改数学模型参数，不声称模拟了某个具体介质的材料变化。
- A=0 时展示平衡直线，λ、T 仍为模型的设定参数，不能从没有振动的图形识别波长。三角函数结果及质点速度为浮点近似。
- 播放只更新本地图形，不自动开始。暂停、调整参数、请求解释及页面隐藏时保存当前时刻，按 0.25 s 取最近网格；播放结束停在 8 s。每一动画帧不写数据库或调用模型，恢复后保持暂停。关闭前若尚未发生保存，恢复到已保存的状态。
- 状态只含五个参数和协议/内容版本，不接受自报的波长、速度结论或成绩。服务端独立重算后进入原课堂活动摘要及 `read_component_activity` 轨迹，探索不评分。
- 不模拟波源启动、边界、反射、干涉、衰减、能量或真实介质测量；0—12 m 是观察视窗，不是绳子两端。该组件不能代替完整波动教学、真实模型质量或专家与学生验收。

配置 Schema 位于 `interactive-labs-v1.schema.json` 的 `wave_lab` 分支，状态 Schema 为 `interactive-wave-state-v1.schema.json`。
