# 平面三角形探索 v1

`triangle_lab` 用三个可配置的二维顶点探索边长、角度、面积和三角形分类。它属于受控组件：模型可选择并配置顶点，学生可拖动顶点或用键盘调整坐标，程序显示结果；探索本身不是正式作答或成绩。

- 坐标范围为 −10 至 10，步长 0.5；初始顶点默认为 A(0,0)、B(4,0)、C(0,3)。
- 半整数坐标网格不能精确构造非退化的等边三角形；不能要求学生用本组件拼出精确等边图形。
- 面积使用顶点行列式的绝对值的一半，边长用欧氏距离。顶点坐标为半整数，行列式和边长平方可在该范围内精确比较；角度及含根号的长度展示为近似值。
- 非退化三角形按边长平方比较等边、等腰或不等边，按最长边平方与另两边平方的关系判断锐角、直角或钝角。顶点共线或重合时，面积为零，角度、周长及三角形类型为 `null`，不把退化图形称作三角形。
- 浏览器状态只含协议版本、课件版本和三个实际顶点。服务端独立检查并重算，不接受浏览器自报的面积、角度或成绩。实际操作通过原课堂的组件活动摘要和按需轨迹读取进入教学上下文。
- 不支持空间几何、任意几何作图、证明或通用定理求解。图形观察可用于形成猜想，不能单独当作证明或掌握证据。未知任务应使用合适文字和已有材料，不宣称此组件支持所有几何。

配置 Schema 为 `schemas/interactive-labs-v1.schema.json` 的 `triangle_lab` 分支；状态 Schema 为 `schemas/interactive-triangle-state-v1.schema.json`。绘图使用现有原生 SVG 交互结构，不引入新的第三方依赖；原项目 JSXGraph 分发和 MIT 许可继续保留。
