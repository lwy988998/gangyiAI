# v5.6.0 统一课堂接入记录

用户已选择 **C「钢一研习工作台」**，以此替换最初计划中的 A 视觉方向；左侧课程目录、分段讲解、独立练习和小结的交互目标保持一致。

## 当前协议

- `/learn`、`/practice`、`/summary` 使用同一个 `lessonId`，旧 `agent-classroom.html` 保留查询参数并转入 `/learn`。
- `start_lesson` 控制指令复用 `lesson-start:<lessonId>` 请求，课时中保存 `initialTeachingTaskId` 与最新 `teachingTaskId`。
- `select_teaching_focus` 由真实主控选择 `sectionId`、`interactionSectionId`、`practiceSectionId`，保存到 `teachingFocus`。三类身份须属于同一课时并匹配用途；已有更新教学任务时，旧任务不能改写焦点。
- `questionKind=interaction` 用于讲解提问，`practice` 用于集中练习。历史诊断、测验、复习用途继续兼容。示范采用 `explanation` 与 `presentation=example`，不成为新的评分题。
- 公共课时读取返回教学状态、实际展示过的交流和已发布评价，排除标准答案、题目快照和评分标准。
- 展示接口支持 `displayedSequences`，仅记录实际呈现的教师文字事件；序号游标本身不表示用户看过所有隐藏输出。
- 同一展示接口接受 `lessonId` 与 `sections:[{id,version}]`，记录实际呈现的板块；学生提交前先保存展示记录，作为已看讲解与提示，避免把折叠内容计入提示经历。
- 历史课件补入概览、检查点、常见错误、资料说明和参考资料，保留原 LearningSession 正文、板块身份、作答与证据。

## 验收结果

- Windows Release 构建与 16 项测试通过，包含原核心测试、旧草稿迁移和订阅取消时序回归。本次学生记录标识与旧复习入口回归也已通过。
- 通过浏览器实际操作验证 C 布局、当前阶段目录、直接跳转、三页切换、单题练习、分题草稿、刷新恢复、历史折叠、停止和同次重试。检查桌面与 390 像素窄屏，窄屏目录可展开且没有横向溢出。
- 多窗口测试确认另一窗口的新草稿没有被旧回复清除。展示记录核对确认已展开示范被记录，未展开内容不算已看提示；纯追问没有增加正式评分。
- 补查修复了旧草稿提交后被重复迁移的问题：迁移只执行一次，保留原缓存，兼容旧题号与独立复习作用域，新输入和明确清空优先。
- 悬浮暂停直接使用最新课时任务，避免刚提交新输入时控制上一任务。恢复和重试会重新接通当前课堂订阅；实际操作与数据库核对确认暂停后未发布新评分，恢复后本次输入只发布一份评价。撤回目标调整也已实际验证。
- 取消订阅后拒绝迟到的状态、文字与连接错误，避免覆盖恢复后的课堂或记录未呈现内容。延迟响应回归同时确认有效反馈、曝光保存与活动连接恢复仍正常。
- 首页默认呈现 AI 建议的第一句，完整文字保存在可展开说明中。图片选择、预览和移除也已实际检查。
- 使用真实模型和虚构学生隔离档案完成规划、备课、开课、实际作答、追问、继续讲解、集中练习、小结判断和下一课准备。评分来自真实模型，未读取私有标准答案冒充学生作答，完成与推进由模型判断。
- 真实模型验收发现题目用途位置和学生记录标识容易混淆，已兼容外层用途参数并明确本次 interactionId。恢复时保留有效动作和原输入，重新建立模型上下文。结构错误保留失败状态与重试入口，未将不完整输出作为完成结果。
- 真实档案副本检查确认原课程、大纲、课件、作答、进度与学科画像记录保留；旧检查点、示范、资料和历史测验分数可在三页读取。
- 使用 Windows MCP 检查独立窗口、课程与画像页签、配置入口，以及 150% 与 100% 缩放显示器间的窗口操作。修复启动器自检参数末尾空格导致误启动的问题，带空格自检退出码为 0。
- 本地安装包和免安装包已生成；SHA256、包内隐私文件排除、主程序与新增资源一致性通过。已备份后更新本机试用程序，安装前后数据库完整性、原记录、AI 配置与凭据核对通过。

持续集成浏览器脚本已适配新布局和有效课时链接。本机浏览器验收采用实际浏览器操作和 Windows MCP；没有运行会卸载程序并清理当前用户配置的发布环境脚本。
